ESM pipeline

A private data tool of the ESportMarket project.

ESM pipeline collects public statistics about professional League of Legends matches. One of its sources is Oracle's Elixir, which publishes match data as public files on Google Drive.

Google Drive limits how often a popular public file can be downloaded each day. With the user's permission, ESM pipeline therefore makes a temporary copy of that public file in the user's own Google Drive, downloads the copy, and deletes it straight away. It does not read, change or delete any other file.

The tool is used only by members of the ESportMarket team. It is not offered to the public.
